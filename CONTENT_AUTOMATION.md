# Автоматизация контента Family OS

## Цель

Собрать один понятный конвейер для Евы:

`идея -> сценарий -> материалы -> монтаж -> проверка -> публикация -> результат`.

Один выпуск может быть подготовлен для YouTube Shorts, TikTok и Instagram Reels одновременно. Никакие пароли, cookies и ключи платформ не попадают в браузер, `preview/index.html`, GitHub или Supabase-таблицы без шифрования.

## Первый рабочий сценарий

1. Ева создаёт карточку выпуска из идеи в разделе `Контент`.
2. Вводит тему и выбирает площадки: YouTube, TikTok, Instagram.
3. ИИ помогает с хуком, сценарием, названием, описанием, хештегами и субтитрами.
4. Ева загружает готовый вертикальный ролик или прикладывает ссылку на исходники.
5. Перед публикацией видит отдельные тексты для каждой площадки и вручную подтверждает выпуск.
6. Сервер отправляет ролик на выбранные площадки, сохраняет ссылки и статусы.
7. Family OS показывает: опубликован / ждёт обработки / ошибка / нужен вход.

## Что делаем по этапам

### Этап 1 — Контент-студия, без аккаунтов платформ

- Карточка `Выпуск`: тема, формат, статус, дата, площадки, видео, сценарий, тексты.
- Шаблоны: Shorts, Reels, TikTok.
- ИИ-черновик сценария: хук, 3–5 сцен, текст на экране, финальный призыв.
- Генератор названия, описания и хештегов для каждой площадки.
- Очередь выпусков: `идея`, `сценарий`, `снято`, `смонтировано`, `готово к публикации`, `опубликовано`.
- Обязательная ручная кнопка `Подтвердить публикацию` — ничего не выходит само без решения Евы.

### Этап 2 — Монтаж и материалы

- Прикрепление исходников, готового MP4, обложки, ссылок и заметок.
- Автосубтитры и текстовая расшифровка через выбранный сервис.
- Черновик монтажа: обрезать паузы, собрать сцены, наложить субтитры, экспортировать вертикальное видео 9:16.
- Результат всегда отправляется в предпросмотр, а не публикуется автоматически.

### Этап 3 — Подключение платформ

Подключения строятся через OAuth: Ева входит в каждый сервис на его официальной странице и даёт разрешение. Токены хранятся только на сервере в зашифрованном виде.

- **YouTube**: YouTube Data API `videos.insert`, загрузка ролика, заголовок, описание, видимость, дата публикации.
- **TikTok**: Content Posting API, Direct Post либо Upload as draft. Для прямого постинга приложение и разрешение `video.publish` должны быть одобрены TikTok.
- **Instagram Reels**: Meta/Instagram Content Publishing API. Нужны подходящий профессиональный аккаунт, Meta app и разрешения публикации.

### Этап 4 — Автовыпуск и результат

- Расписание выпуска по часовому поясу Евы.
- Перед выпуском проверка: есть видео, текст, выбранные площадки и подтверждение.
- Серверная очередь с повторами при временной ошибке.
- История: когда и куда опубликовано, ссылки на ролики, ошибки публикации.
- Позже: загрузка реальных просмотров, лайков и комментариев через официальные API.

## Безопасность

- Никаких логинов, паролей и cookies социальных сетей в Family OS.
- Никаких секретов в GitHub, браузере или клиентском JavaScript.
- OAuth access/refresh tokens хранятся на сервере и шифруются.
- Каждая публикация требует подтверждения пользователя до отправки.
- Публикация для тестовых/непроверенных API-приложений может быть ограничена приватным режимом до аудита платформы.

## Что потребуется от Евы, когда дойдём до подключений

1. Канал YouTube, профиль TikTok и профессиональный Instagram-аккаунт.
2. Доступ к Google Cloud, TikTok for Developers и Meta for Developers для создания приложений.
3. Подтверждение домена `bimbimpatapim.com` там, где его потребуют платформы.
4. Согласие на подключение каждого аккаунта через официальный OAuth-экран.

## Официальные источники

- YouTube: `videos.insert` загружает видео и метаданные; для записи требуется OAuth. Непроверенные API-проекты после 28 июля 2020 публикуют ролики приватными до прохождения аудита: https://developers.google.com/youtube/v3/docs/videos/insert
- TikTok: Direct Post требует зарегистрированное приложение, одобренный scope `video.publish`, OAuth и аудит для снятия ограничений видимости: https://developers.tiktok.com/docs/en/content-posting-api-get-started
- Instagram: API публикации Meta/Instagram подключается только через официальный Meta app и разрешения: https://developers.facebook.com/docs/instagram-platform/content-publishing/

## Ближайшая реализация

Сначала делаем **карточку выпуска** и **очередь контента** внутри текущего раздела `Контент`. Это уже позволит писать планы роликов, сценарии и готовить пакет для трёх платформ без привязки аккаунтов. После этого подключаем ИИ-генерацию текстов, а внешние публикации добавляем только после OAuth-настроек.
